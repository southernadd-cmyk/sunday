# SUNDAY — native Construct 3

[Play](https://southernadd-cmyk.github.io/sunday/construct/) · [Project](https://southernadd-cmyk.github.io/sunday/downloads/SUNDAY-Construct3.c3p) · [Web export](https://southernadd-cmyk.github.io/sunday/downloads/SUNDAY-Construct3-Web.zip)

Open the single-file project in Construct 3 and preview with F5. The native Sprite, Drawing Canvas and Text objects render a five-a-side match with a vertically scrolling pitch and an integrated mutation hand. The game uses the pinned Soccer-JS simulation and the six tested mutations, with adaptive opposition enabled. Choose three environmental powers, drag them onto the pitch, and reuse them after their cooldown. No direct player powers. See [environment design](../docs/ENVIRONMENT_DESIGN.md).nd release. Play freezes during the drag. Invalid drops cancel without spending the token. Squeeze is deployed onto the pitch like other powers. Ten simulation seconds per power (about 6.7 real seconds at the 1.5× arcade pace), one use per match. Tap the clock or press Space to pause; hold the clock or press Escape to return to title. Tap anywhere at half-time or full-time to continue.

The owned scripts synchronize to the existing native web export at build time. No Construct runtime files are edited. To open the source directory, run `npm ci` and `npm run prebuild` first. Native GPU rendering still requires a manual browser/editor playtest. This version is a single-match prototype; roguelite run progression will follow playtesting.
